# 벤치마크 (benchmarks/)

전략 아이디어를 실제 엔진으로 돌려 보고 비교하는 곳입니다.
엔진(`engines/dongpa_engine.py`)은 고치지 않습니다. 모드(공세/방어)를 날짜별로 미리 계산해 엔진에 끼워 넣고 돌립니다.

## 처음 실행

```bash
uv sync --group bench                      # optuna 포함 설치
uv run python -m benchmarks                 # 벤치마크 목록
uv run python -m benchmarks fetch           # Yahoo에서 가격 내려받기 → benchmarks/data/
uv run python -m benchmarks synth           # 상장 전 구간 합성(SOXL_X 등, 2002~)
uv run python -m benchmarks verify_harness  # 끼워 넣기 = 엔진 결과인지 확인 (모두 OK여야 함)
```

엔진을 고친 뒤에는 `verify_harness`, `verify_trend_vix`를 먼저 돌리세요. 둘 다 OK가 아니면 다른 결과도 믿을 수 없습니다.

## 구조

| 경로 | 내용 |
|---|---|
| `suites/` | 벤치마크 하나 = 파일 하나. `python -m benchmarks <파일이름>`으로 실행 |
| `lib/data.py` | 가격 읽기(`load`), 센트 반올림 왜곡을 없앤 확대 가격(`scaled`), 내려받기·합성 |
| `lib/engine.py` | 모드 시계열을 엔진에 끼워 백테스트(`run`), 운용 전략 읽기(`current_params`) |
| `lib/windows.py` | 평가 구간(`WINDOWS`)과 지표(`metrics` = CAGR, MDD) |
| `lib/signals.py` | 모드 신호: 주봉 RSI, 이동평균 추세, VIX, 실현변동성, 고점 대비 낙폭. 전부 전날 종가까지만 사용 |
| `lib/search.py` | Optuna 탐색 공간(신호 계열 `FAMILIES`), 저장된 파라미터 재생(`strategy`), ±10% 이웃(`perturb`) |
| `lib/candidates.py` | 비교용 이름 붙은 전략: 현행, A, B, C |
| `lib/vr.py` | 비교용 라오어 VR 시뮬레이터 (웹 VR 탭은 `engines/vr_engine.py`) |
| `results/` | 결과 요약(json, txt). Optuna 기록(`*.log`)은 커서 git에서 제외 |
| `data/` | 내려받은 가격 (git 제외) |

## 평가 구간

`lib/windows.py`의 `WINDOWS`에 이름으로 모여 있습니다.

- **실제 조건**(`real=True`): 실제 가격, $5만, 스프레드 3주. 계좌가 실제로 매매하는 방식입니다.
- **나머지**: 가격을 확대하고 $10억으로 돌립니다. 2010~13년 SOXL은 $1 안팎이라 익절 1%가 1센트도 안 되기 때문입니다.
- **합성**(`synth=True`): SOXX·QQQ 일간 수익률 × 3 − 비용으로 만든 `SOXL_X`/`TQQQ_X`. 2002·2008 폭락을 포함합니다.

## 새 벤치마크 추가

1. `suites/<이름>.py`를 만듭니다. 첫 줄 docstring이 목록에 설명으로 나옵니다.
2. `main(argv)` 함수를 만듭니다.
3. `uv run python -m benchmarks <이름>`으로 실행합니다.

```python
"""SOXL 200일선 추세 신호를 현행 매매 숫자로 2011~ 구간에서 평가."""
from benchmarks.lib import signals as S
from benchmarks.lib.data import load
from benchmarks.lib.engine import current_params
from benchmarks.lib.windows import WINDOWS


def main(argv):
    _, D, O = current_params()
    win = WINDOWS['11~all']
    eq = win.run('SOXL', lambda t: S.sma_trend(load(t).index, 'SOXL', 200), D, O)
    print('CAGR %.1f%% / MDD %.1f%%' % tuple(x * 100 for x in win.stat(eq)))
```

- 새 신호는 `lib/signals.py`에 함수로 넣습니다. 반환값은 날짜별 `'offense'`/`'defense'` 시리즈입니다. 미래 참조를 막으려면 전날 값까지만 쓰세요(`lag=1`).
- Optuna로 찾고 싶으면 `lib/search.py`의 `suggest_signal`에 분기를 넣고 `FAMILIES`에 이름을 추가합니다.
- 다른 벤치마크와 나란히 비교하려면 `lib/candidates.py`의 `CANDIDATES`에 추가합니다. `mix A current`처럼 이름으로 고를 수 있습니다.
- 새 구간이 필요하면 `WINDOWS`에 추가합니다.

## 벤치마크 목록

| 이름 | 하는 일 |
|---|---|
| `verify_harness`, `verify_trend_vix` | 끼워 넣기·엔진 `trend_vix`가 연구 신호와 같은지 확인 |
| `screen` | 단순 신호 수십 개를 현행 매매 숫자로 한 번에 비교 |
| `drawdowns` | 큰 낙폭 구간(고점·저점·회복일)과 연도별 수익 |
| `mix` | 후보를 계좌 분리로 섞었을 때 (연 1회 리밸런싱 포함) |
| `vr_compare`, `vr_dca` | 라오어 VR 거치식·적립식 vs 현행 vs 보유 |
| `search`, `report`, `robust` | 단일 목표(MDD ≤ 45% 안에서 CAGR) walk-forward 탐색 → 시험 구간 평가 → ±10% 이웃 강건성 |
| `search_mo`, `report_mo` | CAGR·MDD 동시 최적화(파레토) → 평가 |
| `search_pair`, `report_pair` | 현행과 짝지을 전략 탐색 → 혼합 평가 |

탐색은 `--workers N`으로 프로세스를 나눕니다. 각 파일 docstring에 2026-10-12에 실제로 돌린 명령이 있습니다.

## 방법 원칙

1. **미래 참조 금지**: 모든 신호는 전날 종가까지만 씁니다. 엔진도 2026-10-12에 같은 방식으로 고쳤습니다.
2. **긴 역사**: SOXL은 2010년 상장이라 2008급 폭락이 없습니다. 합성 SOXL_X는 실제 SOXL과 상관 0.997, 비용 보정 후 연 오차 0%입니다.
3. **walk-forward**: 학습 구간과 처음 보는 시험 구간을 나눕니다.
4. **강건성**: 상위 후보의 숫자를 ±10% 흔들어 다시 돌립니다. 이웃에서 MDD가 크게 튀면 버립니다.

|---|---|---|---|---|
| 현행 RSI | 96.3% / -34.7% | -14.4% | 4.0% / -69.2% | 35.8% / -69.2% |

| B: SOXL 140일선 + VIX | 55.4% / -36.3% | -24.6% | 10.3% / -40.6% | 36.8% / -41.3% |
| C: SOXX 1년 고점 대비 낙폭 | 66.4% / -26.3% | -10.6% | 12.8% / -44.6% | 31.9% / -44.9% |

## 라오어 VR 5.0 비교 (`lib/vr.py`, `vr_compare`, 2026-10-12)

거치식 VR(2주 사이클, 밴드 ±15%, 풀 사용 50%)을 droomii/vr-simul과 같은 규칙으로 구현했습니다. 사이클 갱신은 전날 종가를 쓰고, 종가 체결과 매수·매도표 지정가 체결 두 방식을 모두 돌렸습니다.
TQQQ 2011~2020 평균 현금비중이 G=10 12.7%, G=40 32.2%로, 라오어가 밝힌 13.2%, 31.8%와 맞습니다.

| SOXL (CAGR / MDD) | 2011~ | 2021~ (실제 $5만) | 2022 | 2023~ |
|---|---|---|---|---|
| 현행 | 57.7% / -56.6% | 96.3% / -34.7% | -14.4% | 141.4% / -25.3% |
| 보유 | 38.2% / -90.5% | 30.1% / -90.5% | -86.6% | 105.1% / -88.0% |
| VR G=10 실력공식 | 37.9% / -89.1% | 29.4% / -89.0% | -78.5% | 85.1% / -85.3% |
| VR G=40 실력공식 | 40.2% / -84.2% | 34.9% / -84.1% | -75.7% | 77.7% / -75.2% |

### 적립식 (`vr_dca`, 결과 `results/vr_dca_compare.txt`)

$5,000 시작 + 2주마다 $250, G=10, 풀 75%. 보유·현행은 같은 날짜 입금을 각자 독립 복사본으로 굴린 근사입니다.
2011~ IRR / 계좌 MDD: TQQQ 보유 40.8% / -81.6%, TQQQ VR 40.1% / -80.4%, SOXL VR 43.7% / -89.1%, SOXL 현행 65.5% / -55.3%.
적립식은 새 입금이 낙폭을 메워 체감 MDD만 줄고, 전략 자체(TWR) 낙폭은 거치식과 같습니다.

### 라오어 표 대조 (TQQQ 2011~2020, 거치식 기본공식)

| G | 라오어 CAGR / MDD | 재현 (매일 종가 점검) |
|---|---|---|
| 10 | 49.47% / -58.41% | 47.6% / -60.6% |
| 20 | 46.16% / -55.72% | 45.4% / -56.9% |
| 30 | 44.12% / -52.48% | 42.7% / -53.8% |
| 40 | 41.86% / -50.03% | 40.1% / -51.4% |

TQQQ 49.68% / -69.92%, QLD 36.19% / -51.72%, 평균 현금비중(13.2%, 31.84%), 적립식 10년 $136만(재현 $126~134만)은 맞습니다.
CAGR 1.5~2%p 차이는 원문에 없는 규칙(시작 비중, 매매표 가격·수량, 매도 대금 재사용, Pool 한도 기준, 체결 방식) 때문으로 보고 재현 오차로 둡니다.
quantstack.app 해석(V까지 되돌림, 판단 시점 Pool)은 MDD가 더 깊어져 더 안 맞습니다.

### 결론

VR은 하락장 초입에 Pool로 사 모으고, Pool이 바닥나면 보유와 같아집니다. 2022 같은 1년짜리 하락에서 TQQQ -70%, SOXL -80% 안팎을 막지 못합니다.
수익은 보유와 비슷하고 낙폭은 현금 비중만큼 조금 작습니다. 효율보다는 기계적인 운용 규칙으로 보고 웹에 기능으로 넣을 예정입니다.

## 2차: 2008 제외, 실제 SOXL 2011~ 기준 (2026-10-12)

사용자 기준 변경: 2008은 자연재해로 보고 제외, 핵심 위험은 2022. CAGR·MDD 동시 최적화(`search_mo`, 학습 2011~2022 → 시험 2023~),
현행과 짝 최적화(`search_pair`, 현행 고정 + 혼합 성과 최대화).

| 전략 | 2011~2026 | 2021~ (실제 조건) | 2022 | 2023~ |
|---|---|---|---|---|
| 현행 RSI | 57.7% / -56.6% | 96.3% / -34.7% | -14% | 141% / -25% |
| 추세 + VIX (`trend_vix` 프리셋) | 76.8% / -43.5% | 91.1% / -43.4% | +36% | 89% / -43% |
| 현행 50 + 추세VIX 50 (계좌 분리) | 70.8% / -42.6% | 93.7% / -37.0% | +11% | 119% / -28% |

- 2021~ 구간 하나로 현행을 이기는 후보는 없음(현행이 그 구간에 맞춘 값). 짝 최적화 두 번 모두 1위가 위 50:50 그대로.
- 추세+VIX는 합성 2002~2010에서 MDD -87%(현행 -69%). 2008급 장기 붕괴에는 약함.
- 엔진 `trend_vix`는 `verify_trend_vix`로 연구 결과와 소수점 넷째 자리까지 일치 확인.
