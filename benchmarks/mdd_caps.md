# MDD 한도별 최적 전략 (2026-10-30)

현행 전략의 장기 MDD가 50%를 넘어, MDD 40·30·20·10% 안에서 CAGR이 가장 높은 전략을 찾았습니다.
탐색 구간은 5·10·15년 세 가지입니다. 결론은 **15년 구간으로 고른 전략만 세 구간 모두에서 한도를 지킨다**입니다.

- 실행: `python -m benchmarks search_mdd` (`suites/search_mdd.py`)
- 결과표: `results/mdd_caps_5y.txt`, `mdd_caps_10y.txt`, `mdd_caps_15y.txt` (같은 이름의 `.json`에 파라미터)
- 프리셋: `config/presets/mdd{40,30,20,10}_*_2026-10-30.json` (웹 설정의 프리셋 목록에 나옴)

## 방법

| 항목 | 내용 |
|---|---|
| 가격 | `data/` (매일 커밋, 증권사 종가 반영), 2026-10-23까지 |
| 구간 | 5년 2021-10-25~, 10년 2016-10-25~, 15년 2011-10-25~ |
| 체결 조건 | 5년은 계좌와 같게 실제 가격 · $5만 · 스프레드 1주. 10·15년은 확대 가격 · $10억 (2011년 SOXL ~$1이라 센트 반올림 왜곡 제거) |
| 신호 계열 | `rsi`(현행 구조), `sma_vix`(이동평균 + VIX), `ddq`(1년 고점 대비 낙폭), `rsi_vix`, `single`(한 모드만) |
| 탐색 | 구간별 · 계열별 Optuna CAGR × MDD 파레토, 5년 3,000회 · 10·15년 2,400회 (계열당), 분할 수 2~40 |
| 선택 | 한도 안 CAGR 상위 15개를 숫자마다 ±10% 흔들어 12번 재실행 → 이웃 중앙값 MDD가 한도 안이면서 이웃 중앙값 CAGR이 가장 높은 것 |
| 교차 확인 | 고른 전략을 나머지 두 구간과 2022년(5년 조건)에도 돌림 |

## 현행 (`config/strategy.json`, 주봉 RSI)

| 5년 | 10년 | 15년 | 2022 |
|---|---|---|---|
| 88.2% / -34.7% | 79.1% / -42.7% | 61.6% / -56.6% | -14.7% |

CAGR / MDD. 최근 5년 MDD는 -34.7%(저점 2022-10-12)이고, 50%대는 15년(저점 2015-09)입니다.

## 프리셋 파라미터

엔진의 `trend_vix`는 라벨이 뒤집혀 있습니다: 강세장(모멘텀 > SMA×(1+밴드) 그리고 VIX < low)이 `defense`, 그 밖이 `offense`.

| 프리셋 | 모드 전환 | 방어 (N / 매수 / 익절 / 보유 / 손절) | 공세 |
|---|---|---|---|
| `mdd40_single` | 없음 (두 모드 같은 숫자) | 5 / 4.5% / 2.75% / 8일 / 18% | 같음 |
| `mdd30_trend_vix` | QQQ 50일선 ±4%, VIX 18 / 21 | 39 / 5.0% / 9.25% / 3일 / 23% | 7 / 7.0% / 2.25% / 8일 / 22% |
| `mdd20_trend_vix` | QQQ 50일선 ±4%, VIX 28 / 32 | 33 / 3.25% / 6.25% / 6일 / 27% | 5 / 6.5% / 1.25% / 28일 / 7% |
| `mdd10_single` | 없음 (두 모드 같은 숫자) | 16 / 4.5% / 5.25% / 3일 / 24% | 같음 |

- 40%·10%는 모드 전환 없이 한 벌의 숫자가 이겼습니다. 한도는 분할 수(= 한 번에 넣는 비중)로 맞춰집니다: N5 → MDD 40%, N16 → 10%.
- 30%·20%의 강세장 쪽은 분할 30~40개로 아주 조금씩 사고 크게 익절하고, 약세·고변동(VIX 높음) 쪽은 분할 5~7개로 크게 사서 짧게 익절합니다. 하락을 크게 사는 구조라 2022에서 플러스입니다.

## 엔진에 없는 후보: 30% `ddq`

15년 30% 한도 1위는 `ddq`였습니다: SOXX가 1년 고점보다 6% 넘게 빠지면 방어, 고점 -4.8% 안으로 돌아오면 공세 (`rec_frac` 0.8 × 6%).

| 15년 | 10년 | 5년 | 2022 |
|---|---|---|---|
| 38.2% / -28.7% | 44.9% / -26.1% | 48.5% / -21.6% | +5.8% |

`mdd30_trend_vix`보다 5년 CAGR이 13%p 높지만, 엔진에 고점 대비 낙폭 모드가 없어 프리셋으로 만들지 않았습니다.
쓰려면 엔진 `mode_switch_strategy`에 추가해야 합니다 (`trend_vix`처럼 연구 신호와 일치 확인 필요).
파라미터: `dd 0.06, rec_frac 0.8, ticker SOXX`, 공세 N3 / 7.0% / 4.75% / 3일 / 37%, 방어 N7 / 2.5% / 2.75% / 35일 / 8%.

## 해석

- 한도를 낮출수록 CAGR이 빠르게 줄어듭니다. 15년 MDD를 40% 안으로 묶으면 5년 CAGR이 88% → 59%입니다.
- 현행은 최근 5년만 보면 가장 좋지만 그 구간에 맞춘 숫자이고, 15년 MDD는 가장 깊습니다.
- 15년에도 2008급 장기 붕괴는 없습니다. 이전 합성(2002~) 연구에서는 모든 후보의 MDD가 2008에서 커졌습니다.
- 수수료 0, 슬리피지 없음 가정입니다. 0.07% 수수료면 현행 5년이 90.1% → 67.8%(스프레드 없이)까지 떨어졌으므로, 분할이 많고 익절이 작은 전략일수록 더 깎입니다.

## 다시 돌리기

```bash
uv sync --group bench
# 구간(Y = 5, 10, 15) × 계열마다. 5년 3000회, 10·15년 2400회 (12 workers 기준 계열당 5~10분)
for f in rsi sma_vix ddq rsi_vix single; do
  uv run python -m benchmarks search_mdd search $f 200 --years 15 --workers 12
done
uv run python -m benchmarks search_mdd report rsi sma_vix ddq rsi_vix single --years 15
```

Optuna 기록은 `results/mdd_<계열>.log`(5년), `mdd10y_*.log`, `mdd15y_*.log` (git 제외)입니다.
