# 공세→안전 전환 손실 연구 (2026-11-01)

현행 RSI 전략(`config/strategy.json`)에서 공세에서 안전으로 넘어갈 때 손실이 크다는 문제를 진단하고 대책을 백테스트로 비교한 기록입니다.
데이터는 `data/` 2026-10-28까지. 재현: `uv run --group bench python -m benchmarks transition --workers 12` → `benchmarks/results/transition.txt`.

## 1. 진단: 손실은 전환 '전'에 난다

- 엔진의 로트는 매수한 날 모드의 익절·손절·최대보유일을 끝까지 들고 갑니다(`engines/dongpa_engine.py` `run_backtest`).
  안전으로 바뀌어도 공세 로트(익절 3.41%, 손절 18.1%, 47일)는 그대로 남습니다.
- 그런데 15년(2011-10~) 전환 31번을 보면 큰 낙폭은 전환 직전 20일에 이미 납니다. 전환 후 30일은 대개 반등합니다.

| 전환일 | 전환 전 20일 자산 | 전환 후 30일 자산 | 전환 전 20일 SOXL |
|---|---:|---:|---:|
| 2015-08-24 | -23.5% | -2.1% | -26.8% |
| 2018-10-22 | -22.1% | -10.4% | -32.2% |
| 2019-06-03 | -35.2% | +35.2% | -44.1% |
| 2022-01-24 | -12.8% | -0.2% | -33.1% |
| 2023-10-30 | -14.0% | +43.3% | -20.0% |

- 원인: 모드를 정하는 QQQ 주봉 RSI가 늦게 꺾입니다. 그동안 공세(4분할, 큰 트렌치)가 떨어지는 SOXL을 계속 사고, 손절 18.1%가 연달아 나갑니다.
- 15년 최대 낙폭 -56.6%(2015-06~09)도 84일 중 69일이 공세였습니다.
- 2026-10: 백테스트는 10-28까지 공세. 10/5~10/15에 산 공세 로트 7개가 손절되어 낙폭 -30.6%(10-22).

## 2. 방법

- `benchmarks/lib/transition.py`의 `Policy`로 규칙을 정의합니다. 엔진은 고치지 않고 `decide_mode`를 감싸
  다음 날 모드와 열린 로트를 바꿉니다. 그날 저녁에 바꾼 것이 다음 날 LOC 주문에 반영되는 것과 같습니다.
- `keep`(현행)을 주입하면 엔진 결과와 자산곡선 차이 0. `verify_harness` OK.
- 구간
  - **학습**: 최근 5년(2021-10-25~), 실제 가격·$5만·스프레드 1주 (계좌와 같은 조건)
  - **시험**: 10년(2016-10-25~), 15년(2011-10-25~). 둘 다 학습 5년을 포함합니다.
  - **oos**: 2011-10-25~2021-10-24. 학습과 겹치지 않는 진짜 시험 구간입니다.
  - **syn**: 합성 SOXL_X 2002~2010 (2008 폭락 포함)
- 학습 Calmar(CAGR/|MDD|)로 순위를 매기고, 상위 규칙은 숫자를 ×U(0.9, 1.1)로 흔들어 다시 돌렸습니다.

## 3. 시험한 대책

| 계열 | 내용 |
|---|---|
| 전환 시 공세 로트 처리 | 그대로(keep) / 전부 청산 / 손실 로트만 청산 / 안전 익절·보유일로 바꿈 / 손절을 체결가 -5~-15%로 당김 |
| 조기 안전 | SOXL이 N일 고점보다 X% 떨어지면 안전 강제 |
| 공세 손절 연속 브레이커 | 공세 손절이 W거래일 안에 K번 나오면 H거래일 안전 강제 |
| 매수 중지(pause) | 전환 예고(이번 주를 오늘 종가로 마감한 잠정 주봉 RSI) / 전환 후 N일 / 양방향 / 손절 연속·낙폭 시 / 전량 청산 + N일 현금 |

총 235개 규칙(전환·조기 안전·브레이커 186개 + 매수 중지 49개).

## 5. 해석

1. **전환 시 청산은 바닥 매도입니다.** 손실은 이미 전환 전에 났고 전환 후엔 반등이 많아서, 그때 팔면 MDD가 오히려 깊어집니다.
2. **5년만 보고 고르면 과적합입니다.** 학습 1위는 oos MDD가 현행보다 나쁩니다(-58.6%).
   학습 순위와 oos 순위 상관은 매수 중지 제외 186개에서 0.19, 전체 235개에서 0.32입니다. 10년·15년은 학습 5년을 포함해서 좋아 보이기 쉽습니다.
3. **공세 손절 연속 브레이커가 일관되게 효과가 있습니다.** 36개 변형 중 30개가 oos에서 MDD가 낫고 CAGR이 1%p 이내 이상입니다.
   진단과 맞는 단순한 장치이고 숫자를 흔들어도 결과가 거의 같습니다. 단, 이 계열은 시험 구간 결과도 보고 골랐으므로 순수한 시험 결과는 아닙니다.
4. **안전 강제는 5일이 적당합니다.** 손절 2번/10거래일 고정, 나머지 현행 그대로 일수만 바꾼 결과:

   | 4 | 91.0% / -28.6% | 81.0% / -40.9% | 50.1% / -46.9% | 1.9% / -70.1% | -14.5% |

   1~3일은 손절 연쇄를 못 끊고(oos MDD -49~-53%), 8일 이상은 반등을 놓쳐 CAGR이 떨어집니다.
   4~7일은 oos가 거의 같은 평평한 구간이고 5일은 그 가운데라 숫자가 조금 바뀌어도 크게 흔들리지 않습니다.

   2022년(2021년 말 종가 기준, 실제 조건): 현행 -13.0% / 연중 MDD -34.7%, 브레이커 5일 -4.9% / -28.6%, SOXL 보유 -85.8%.
   차이는 4월(-19.7% → -14.9%)과 9월(-12.3% → -9.9%).
5. **매수 중지는 효과가 없습니다.** 학습에서 현행보다 나은 규칙 0/49, oos 9/49.
   전환 시점 기준 중지는 2026-10을 못 막고(그때는 전환 예고조차 없었음), 전환 후 중지·현금은 반등 매수를 놓칩니다.
   같은 손절 연속 신호라도 안전 모드(11분할로 계속 매수)가 매수 중지보다 모든 구간에서 낫습니다.
6. **2008급 장기 붕괴(syn)에는 이득이 없습니다.** 공격형은 syn MDD -78%로 더 나빠집니다.

## 6. Optuna 전체 최적화 (`search_breaker`, 2026-11-01)

RSI 임계값 5개, 안전·공세 파라미터 각 5개, 브레이커 3개(손절 횟수 1~4, 창 3~30일, 안전 0~15일, 0 = 끔)를
최근 5년 CAGR·MDD 2목적으로 함께 찾았습니다. 2,868회, 현행과 현행+브레이커를 시드로 넣었고 고르는 것은 학습 데이터만 봤습니다.
재현: `search_breaker search 300 --workers 12` 후 `search_breaker report` → `benchmarks/results/search_breaker.txt`.

| 전략 | 학습 5년 | 10년 | oos | syn | 2026-10 |
|---|---|---|---|---|---:|
| 현행 | 89.0% / -34.7% | 79.6% / -42.7% | 48.1% / -56.6% | 4.0% / -69.2% | -24.7% |
| 현행 + 브레이커 (= 학습 Calmar 1위) | 89.6% / -30.4% | 80.9% / -37.7% | 50.0% / -46.8% | 1.0% / -70.0% | -14.3% |
| 학습 MDD 30% 이내 픽 | 55.1% / -28.7% | 52.4% / -31.9% | 36.6% / -44.3% | 3.3% / -64.0% | -9.8% |
| 학습 MDD 25% 이내 픽 | 42.8% / -20.7% | 33.5% / -44.0% | 21.0% / -44.0% | 12.4% / -40.9% | -12.4% |

- **더 나은 조합을 못 찾았습니다.** 학습 Calmar 1위가 시드로 넣은 현행+브레이커 그대로입니다.
  현행 숫자가 애초에 2021~2026에 맞춘 값이라, 같은 5년으로 다시 찾아도 더 올라갈 자리가 거의 없습니다.
- MDD 한도 픽은 CAGR을 크게 포기하는데 oos MDD는 -44%로 학습(-21~-29%)보다 훨씬 깊습니다. 낮은 MDD가 필요하면
  15년으로 고른 기존 프리셋(`config/presets/mdd30_trend_vix`, 15년 35.5% / -25.7%)이 낫습니다.
- 파레토 15개의 학습→oos Calmar 순위 상관 -0.41: 5년 최적화는 다른 10년을 예측하지 못합니다.
- **현행 숫자는 뾰족한 봉우리 위에 있고, 브레이커가 그 주변을 단단하게 합니다.**
  현행 숫자 전부를 ±10% 흔든 16개(같은 흔듦에 브레이커 유무만 다르게):

| ±10% 이웃 중앙값 | 학습 5년 | oos | oos 최악 MDD |
|---|---|---|---:|
| 현행 | 79.5% / -39.2% | 46.4% / -52.5% | -58.0% |
| 현행 + 브레이커 | 82.7% / -33.4% | 47.6% / -45.0% | -48.6% |

  브레이커를 켜면 MDD가 작아지는 경우가 학습 13/16, oos 15/16입니다.
  현행 숫자를 조금만 바꿔도(실제로는 시장이 조금 달라져도) 무너질 수 있는데, 브레이커가 그 위험을 줄여 줍니다.

## 7. 추천과 남은 일

- 추천: **공세 손절이 10거래일 안에 2번 나오면 다음 5거래일은 안전 모드** (나머지 현행 그대로).
  oos 48.1% / -56.6% → 50.0% / -46.8%, 2026-10 -24.7% → -14.3%.
- **적용 (2026-11-01)**: 엔진 `StrategyParams.sl_breaker_*`, `config/strategy.json`에
  `sl_breaker_count 2 / window 10 / days 5 / start 2026-11-02`. 오더북 `다음모드`와 trader는 같은 엔진을 따르고 웹 설정에도 노출.
  연구 훅과 엔진 결과가 5·10·15년 모두 자산곡선 차이 0.
- **시작일을 둔 이유**: 엔진은 계좌 시작일부터 장부를 다시 계산합니다. 소급 적용하면 메인 계좌의 2026-10 매매가
  달라져 장부(현금 $30,350 → $37,505, 보유 141주 → 123주)가 실제 증권사 잔고와 어긋납니다.
  시작일 이전 손절은 세지 않으므로 세 계좌 모두 장부·다음 거래일 주문이 적용 전과 같습니다.
  웹 백테스트에서 과거 효과를 보려면 설정의 브레이커 시작일을 비우세요.
