## 사이클 계산 (행 = 2주)

- 기간: `시작 = 이전 시작 + 14일`, `종료 = 시작 + 13일`. 새 행은 이전 종료 + 1일 08:00(KST) 지나면 생김.
- 평가금 `M = 수량 N × 단가 O`. 단가는 종료일 종가(진행 중이면 최신가).
- Pool `Y = 이전 Pool + 적립 X − 매수금액 U − 수수료 V` (매도는 U가 음수라 Pool로 들어감).
- P/V `AL = Pool / V`.
- **상승률 `AO`**
  - `Grade`(AM)가 숫자면 VR 5.0: `1 + P/V/G + 실력편 × (평가금/V − 1) / (2√G)`. G는 `Cycle, Step` 설정(`26, 1`)대로 26사이클마다 1씩 증가.
  - 비어 있으면(현재) **상승률 표**: P/V가 표의 하한 이상인 첫 행, 평가금 < V면 왼쪽 열, > V면 오른쪽 열.
- **다음 V** `H(n+1) = round(H(n) × AO(n) + 적립 X(n+1), 2)`. 추가목돈이 있는 사이클은 Pool 증가 비율만큼 V를 같이 키움.
- **밴드**: 상승률 표 모드는 최소 `V × 0.8`, 최대 `V × 1.25`. VR 5.0 모드는 `× 0.85`, `× 1.15`.

## 매수표·매도표 (현재 사이클)

- 매수표: 보유 Q에서 시작해 `가격 = V최소 / Q`, `V최소 / (Q+1)`, … 1주씩 내려감. 누적 매수금이 Pool 한도(사이클 시작 Pool의 풀 제한%)를 넘기 직전까지. 주문은 8주(`AQ6`)씩 묶어 그 가격에 냄.
- 매도표: `가격 = V최대 / Q`, `V최대 / (Q−1)`, … 1주씩 올라감. 현재가 × 1.4(`AV3`)를 넘는 가격은 생략.
- 사이클 안에서 체결된 수량을 반영해 표를 다시 그림. 매도 대금은 그 사이클 매수 한도에 다시 들어가지 않음.
- 수수료: 매수·매도 0.07%(내림), 매도 시 SEC fee 0.00051%(최소 0.01) — Pool 평가(AC열) 계산용.

## 웹 VR 탭 (`engines/vr_engine.py`, `config/vr/<id>.json`)

시트를 대신하는 웹 구현입니다. 사용자 결정(2026-10-12): V는 **실력공식(VR 5.0)**, 체결은 **가격으로 추정**, LOU(라오어 따라하기)는 넣지 않음.

| 항목 | 시트 | 웹 |
|---|---|---|
| V 갱신 | 상승률 표 (G 비우면) | `V + P/G + (E−V)/(2√G) + 적립`, E·P는 직전 사이클 마지막 종가 기준 |
| G | `Cycle, Step` = `26, 1` | `g`, `g_step_cycles`, `g_step` (기본 10, 26사이클마다 +1). `origin_date`(VR 시작일)부터 셈 |
| 주차 | 시작일부터 지난 주 | `origin_date`부터 지난 주 (`(사이클 시작 − origin_date) ÷ 7`). 예전 `start_week` 파일은 시작일로 자동 환산 |
| 밴드 | 표 모드 -20% / +25% | `band_pct` ±15% |
| 매수표 | V최소/Q부터 1주씩, 8주 묶음, 사이클 시작 Pool의 75%까지 | 같음 (`buy_unit`, `pool_limit_pct`). 묶음 가격은 묶음에서 가장 낮은 단계 |
| 매도표 | V최대/Q부터 1주씩, 현재가 +40%까지 | 같음 (`sell_unit`, `sell_cap_pct`). 기준가는 사이클 시작 직전 종가 |
| 체결 | 매매 시트에 직접 입력 | 사이클 시작에 낸 예약주문이 일별 저가(매수)·고가(매도)에 닿으면 체결, 갭이면 시가. `order_type: "loc"`면 종가 |
| 보정 | — | `adjustments: [{"date", "shares", "pool", "v"}]` — 그 날짜가 든 사이클 시작에 값을 덮어씀 |
| 적립 변경 | 매매 시트 `추가적립` | `deposit_changes: [{"from", "deposit"}]` |

VR 시작일은 시트와 같은 2023-07-01(`origin_date`)이라 G는 85사이클 지난 13에서 시작하고, 2027-06-26 사이클에 14가 됩니다 (2026-10-14 사용자 결정).
