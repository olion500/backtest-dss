# 전략 탐색 연구 (research/)

공세/방어 모드 전환 신호와 모드별 매매 숫자를 백테스트로 찾는 스크립트 모음입니다.
엔진(`engines/dongpa_engine.py`)은 고치지 않고, 미리 계산한 일별 모드 시계열을 엔진에 끼워 넣어 돌립니다.

## 실행

```bash
cd research
../.venv/bin/python fetch.py data      # Yahoo에서 SOXL·QQQ·SOXX·TQQQ·VIX 등 내려받기
../.venv/bin/python synth.py           # 합성 3배 SOXL_X / TQQQ_X, 2배 USD_X (2001~)
../.venv/bin/python verify.py          # 하네스 = 엔진 RSI 결과 일치 확인
./launch.sh <family> <target> <trials/worker> <workers> <train_start> <train_end> <tag>
../.venv/bin/python report.py <tag> <family> <target> [topk]   # 학습 상위 trial의 2021~ 성과
../.venv/bin/python robust.py <tag> <family> <target> [topN]   # 파라미터 ±10% 이웃 강건성
../.venv/bin/python mix.py             # 후보·현행 자금 분할 혼합
```

## 파일

| 파일 | 역할 |
|---|---|
| `harness.py` | 엔진 `decide_mode`를 바꿔 끼워 외부 모드 시계열로 백테스트. 가격 스케일업(센트 반올림 왜곡 제거) |
| `signals.py` | 모드 신호: 주봉 RSI, SMA 추세, VIX, VIX 기간구조, 실현변동성, 고점 대비 낙폭. 모두 전날 종가까지만 사용 |
| `opt.py` | Optuna 목적함수(학습 MDD ≤ 45% 제약 + CAGR), 신호 계열 정의 |
| `synth.py` | SOXX·QQQ 일간수익률 × 레버리지 − 비용으로 상장 전 구간 합성 |
| `candidates.py` | 비교용 후보(현행, A, B, C) |
| `studies/*.robust.json` | 전체 기간 재학습 상위 후보와 이웃 강건성 결과 |

## 방법

1. **미래 참조 제거**: 모든 신호는 전날 종가까지만 사용합니다. 엔진도 2026-10-12에 같은 방식으로 고쳤습니다.
2. **합성 데이터로 긴 역사 확보**: SOXL은 2010년 상장이라 2008급 폭락이 없습니다. SOXX 3배 합성은 실제 SOXL과 상관 0.997, 연 오차 0%(비용 보정 후)이고 2002년 -95%, 2008년 -94%를 포함합니다.
3. **walk-forward**: 2002~2020으로 학습하고 처음 보는 2021~2026으로 평가합니다. 2011~2020만으로 학습하면 6개 계열 전부 2022에서 MDD -55~-80%가 나왔습니다.
4. **강건성**: 전체 기간으로 재학습한 상위 후보의 숫자를 ±10% 흔들어 16번 다시 돌립니다. RSI 계열은 이웃에서 MDD가 -80%까지 튀어 제외했습니다.

## 결과 요약 (2026-10-12, CAGR / MDD)

| 전략 | 2021~ (실제, $5만, 스프레드 3주) | 2022 | 2002~2010 합성 | 2002~ 전체 |
|---|---|---|---|---|
| 현행 RSI | 96.3% / -34.7% | -14.4% | 4.0% / -69.2% | 35.8% / -69.2% |
| A: SOXL 160일선 + VIX | 72.1% / -37.6% | -17.9% | 9.0% / -42.2% | 36.2% / -43.5% |
| B: SOXL 140일선 + VIX | 55.4% / -36.3% | -24.6% | 10.3% / -40.6% | 36.8% / -41.3% |
| C: SOXX 1년 고점 대비 낙폭 | 66.4% / -26.3% | -10.6% | 12.8% / -44.6% | 31.9% / -44.9% |
| A 50 + C 50 (계좌 분리) | 69.4% / -27.7% | -14.2% | 11.0% / -43.4% | 34.4% / -43.4% |

현행은 2021~ 성과가 가장 좋지만 2021~2026을 보고 맞춘 숫자이고, 2008급 폭락에서 MDD -69%입니다.
